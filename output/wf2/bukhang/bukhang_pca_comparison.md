## 4. 룰이 잡지 못한 실사 결함 (결함급 16건)

연식(3년) 기준으로 G 룰은 모두 🟢가 되지만, 실사는 다음을 결함으로 지적했다. Defects & CapEx 합계는 약 38.1억원이다(즉시 5.8, 단기 13.5, 장기 18.8, p30).

- **누수 (G06·G02·G04):**
  - 램프 트렌치·E.J 구간 누수가 심각하다(하부층 물고임, 뿜칠 탈락, p80).
  - 발전기실·EPS실 천장이 샌다(p16, p80).
  - EPS A존(7F·8F)에서 누수가 진행 중이다(p182).
  - 하역장·10층 주차장 균열 보수부가 파손돼 구조체 부식이 우려된다(p17).
  - 4~5층 Berth 배수가 불량하다(p80).
- **결로 (CL03):**
  - 4~5층 창고 천장과 지하 계단실에 곰팡이가 피었다.
  - 작업장↔저온창고 벽체에 결로가 생겨 도장이 흘러내린다(p85).
  - 지하 전실 천장이 결로·누수로 훼손됐다(p149).
- **법규·안전 (G09·FR02):**
  - 가설 컨테이너 10개소와 8층 가설 창고의 신고 여부를 확인해야 한다(p41).
  - 피난 동선에 물품·랙이 적치돼 있어 즉시 치워야 한다(p73, p91).
  - 높이 60 m를 넘는 건물인데 측뢰설비가 없다(p155).
  - 램프·하역장 상부 철골보의 내화 뿜칠이 박리됐다(p16).
- **비상발전기 (G04):** 예비전원설비 정기검사(2025-04경)의 합격 자료가 제출되지 않았다(p28).

시사점: songon1 때와 같은 패턴이다. 신축 자산에서는 연식 룰이 🟢로 나오고, 실제 결함은 시공·운영 하자에서 나온다. 도면 스크리닝으로는 잡을 수 없는 영역이므로 보고서의 "PCA·현장 실사를 대체하지 않는다"는 전제가 그대로 적용된다.

## 5. 도면(2021.03)과 준공·운영 상태의 차이 (실사 기술)

- **연면적:** 착공 시 112,038.73 ㎡, 사용승인 111,959.24 ㎡다. 도면 A-101 표가 이미 사용승인 면적과 같아서, 받은 도면이 설계일자 표기만 남은 준공도서일 가능성이 있다(골든 README 검토 항목).
- **운영 온도대:** 전 층 저온 설계였으나 5층 일부·9층은 상온으로 운영 중이다.
- **도면과 현장이 다른 설비:**
  - 도면에 있으나 현장에 없는 것: 누수감지기, 전력제어 시스템, 측뢰설비, EV 충전 볼라드
  - 도면과 사양이 다른 것: 저수조(STS → SMC), 냉동기계실 팬(덕트 → 벽부형)
  - 도면에 없는 것: 주차관제설비, 이동통신 중계기, 사무실 칸막이 분할, 가설 건축물, 임차인 이동식 지게차 램프

## 6. 제안 (판단은 사용자)

1. **SP02 서술 보강:** 최종 보고서는 미달을 "9F 한 층"으로 적었다. 실사 실측을 반영하면 창고 전 층이 배관 하부 7.85~8.03 m다. 보고서에 반영하려면 CLAUDE.md 재진입 절차를 따른다. W2-⑤ 스펙 정정 시 `correct`에 출처 TDD p68을 넣는다.
2. **⚪ 입력 보완:** 실사로 확인된 사용승인일, 바닥하중, 램프 경사, 냉매, 3F~9F 기둥 간섭(언급 없음 → false, medium)을 G2 `correct`(출처 TDD 페이지)로 넣으면 ⚪ 19건 중 13건이 풀린다. 남는 6건은 G03·CL02·FR01·FR06(실사에도 없음)과 CL03·V02(임계값 미정)이다. 이 경우 CL01·SP05가 🔴로 새로 생긴다. 다만 현재 모드는 '도면 단독'이라 실사 자료를 입력에 섞을지는 사용자가 정할 일이다.
3. **판독 기준 개선 후보:**
   - 유효층고는 도면에 배관 하단이 없으면 '보 하단'임을 `precision`/`note`로 남기고, G2에서 배관 반영 여부를 묻는다.
   - 1F 층고처럼 2개 층을 쓰는 저온 구역은 층고 판독 규칙에 넣는다.
   - 회전반경은 램프 곡선부 R을 우선한다.
4. **골든 확정:** `tests/golden/bukhang/README.md`의 검토 항목을 확인하고 확정한다.
   - 램프 경사 기준값(10.69% vs 8.76%)
   - 9F 온도대(설계 저온 vs 운영 상온)
   - 유효층고 기준(배관 하부 vs 보 하단)
   - 하중 국·영문 불일치
