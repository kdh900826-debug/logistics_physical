# 필드 추출 가이드 (W1-② / W2-② / W2-③)

im-analyst와 drawing-extractor가 공통으로 따른다. 원칙은 **적힌 값을 그대로 전사**하는 것이다. 계산·보간·추정은 하지 않는다. 단위 환산은 스크립트가 한다.

## 공통 규칙

1. 값이 없으면 필드를 만들지 않는다(null 금지). 도면 추출은 대신 `missing`에 사유를 남긴다.
2. 원 단위를 `unit`에 그대로 쓴다: `평`, `㎡`, `kN/㎡`, `kg/㎡`, `t/㎡`, `mm`, `m`, `%`, `kW`, `kVA`.
3. 범위 표기는 범위 그대로 두지 말고 precision으로 표현한다.
   - "1.5t 이상" → value 1.5, precision `lower_bound`
   - "7.5% 이하" → value 7.5, precision `upper_bound`
   - "6.41~8.52%" → 불리한 쪽 값을 고르지 말고 **두 값을 별도 후보로** 기록하고 `conflict: true`
4. "약", "≒" → precision `approx`. "약 3만 평"처럼 끝자리가 0인 반올림 → `rounded`.
5. 같은 필드가 여러 곳에 다르게 적혀 있으면 전부 기록하고 `conflict: true`.
6. `raw_text`에 근거 구절을 짧게 인용한다(20자 안팎).
7. 층별 값은 `floors[]`에 넣는다. "1~3층 1.5t"처럼 묶어 적힌 값은 해당 층마다 같은 값을 넣고 `raw_text`에 묶음 표기를 그대로 둔다(이것은 전사이지 추정이 아니다). "기준층", "상층부"처럼 층이 특정되지 않으면 동 단위 note로만 남긴다.
8. 동 구분: `asset_meta.yaml`의 동 id를 쓴다. IM이 동을 나누지 않았고 자산이 여러 동이면 `_asset`에 넣는다.

## 도크 수 접안 검증 (dock_count)

2026-10-15 사용자 지시(hwaseong). 주차계획표의 '화물' 대수는 출발점일 뿐이다. 층마다 아래를 거친 수만 dock_count에 넣는다.

1. **출발점:** 주차계획도의 층별 주차대수 표 '화물' 값과 층별 화물주차 구획 위치를 확인한다.
2. **층별 평면도 대조:** 화물주차가 있는 층마다 건축 평면도(창고층)와 그 층 주차계획도 평면을 같이 본다. 스캔 도면은 구획 주변을 200dpi 이상으로 확대해 본다.
3. **접안 판정:** 구획마다 짧은 변이 창고 외벽(또는 창고와 바로 붙은 하역장·창고전실 벽, 실내 하역장의 도크면)에 직각으로 맞닿는지 본다. 다음 근거가 있으면 접안으로 본다(하나 이상, note에 적는다):
   - 맞닿은 벽의 개구부: 스피드도어·셔터·OHD
   - 도크레벨러 표기
   - 야드가 창고 바닥보다 낮음(예: 야드 `FL-1000`, 부분단면 단차)
   - 상부 캐노피
4. **제외:** 다음은 세지 않는다.
   - 창고 벽에서 떨어진 야드 안의 화물주차
   - 옥상 주차장의 화물주차 중 창고 벽에 닿지 않는 것
   - 대기 주차·회차 공간
   - 일반(승용·경형) 주차

   옥상(아래층 지붕) 위 야드라도 구획이 그 층 창고(전실) 벽에 닿아 있으면 포함하고 note에 "옥상 야드이나 창고전실 벽 접안"이라고 적는다(hwaseong 4F: 3F 지붕 위 4F YARD 16구획이 창고전실 외벽에 접안 → 포함).
5. **수 확정:** 접안으로 판정한 구획을 직접 센다(번호가 있으면 번호로 대조한다).
   - 표 값, 평면 주기(예: '소형화물차 17대'), 실제 구획 수가 다르면 실제 구획 수를 값으로 쓰고 나머지 표기는 note에 남긴다(hwaseong 4F: 표 16·평면도 16·주차계획도 주기 17·실제 16 → 16).
   - 구획을 셀 수 없을 만큼 흐리면 표기값들을 후보로 모두 넣고 `conflict: true`.
6. **기록:**
   - `raw_text`: 층별 주기 원문.
   - `note`: 층마다 `층: 표 n / 접안 확인 n / 제외 n(사유) / 근거(벽·개구부·FL 단차) / 시트`를 적고, 끝에 합산식을 적는다.
   - `source_locator`: 대표 시트(주차계획도 표)를 남기고, 층별 평면도 시트 번호는 note에 적는다.
   - 접안이 확인된 층은 `direct_truck_access`도 그 층에 true로 기록한다.
   - 화물주차가 없는 층은 note에 "화물주차 없음"이라고 적는다.
7. **확인할 수 없을 때:** 평면도가 없거나 접안 여부를 판정할 수 없으면 표 값을 그대로 쓰지 않는다. 판정한 층만 합산하고 판정 못 한 층을 note에 적는다. 한 층도 판정하지 못하면 `missing_reason: 판독불가` 또는 `도면없음`으로 남긴다.

## 도면 판독(비전) 추가 규칙

- 1차(blind)에서는 IM 파일과 `w2_02_*.json`을 열지 않는다.
- 값마다 판독한 타일 경로(`source_locator.tile`)와 타일 내 비율 좌표(`tile_box: [x0, y0, x1, y1]`, 0~1)를 남긴다. 스크립트가 페이지 좌표로 바꾸고 크롭을 만든다.
- 글자가 흐려 확신이 없으면 값을 만들지 말고 `missing_reason: 판독불가`.
- `source_locator.page`는 입력 도면 PDF의 페이지 번호다.
