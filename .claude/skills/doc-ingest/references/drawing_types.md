# 도면 유형 분류 기준 (W2-③ 1단계)

drawing-classifier가 썸네일·표제란 크롭을 보고 `w2_03_sheet_index.json`의 각 장에 `drawing_type`, `sheet_no`, `title`, `building_id`, `floors`, `readable`을 채운다.

## 유형과 식별 단서

| drawing_type | 표제란·도면번호 단서 | 화면 단서 |
|---|---|---|
| 배치도 | A-0xx, "배치도", "SITE PLAN", "대지종횡단면도" | 대지 경계선, 도로, 건물 외곽, 주차·야드 |
| 면적표 | "면적표", "개요", "건축개요" | 층별 면적 표 |
| 평면도 | A-1xx, "평면도", "FLOOR PLAN", "n층" | 그리드 축(X1·Y1), 실명, 도크·램프 |
| 단면도 | A-3xx, "단면도", "SECTION" | 층 레벨 FL, 층고 치수, 지붕 |
| 입면도 | A-2xx, "입면도", "ELEVATION" | 외관, 패널 줄눈, 창호 |
| 외벽상세도 | A-5xx, "부분상세", "외벽상세", "WALL SECTION" | 패널 단면, THK, 심재 표기 |
| 마감표 | "마감표", "실내재료마감표", "FINISH SCHEDULE" | 실별 마감재 표 |
| 방화계획도 | "방화구획", "방화계획" | 구획선, 방화셔터 |
| 단열계획도 | "단열계획" | 단열재 범례 |
| 구조일반사항 | S-001~S-00x, "구조일반사항", "GENERAL NOTES" | 설계하중표, 재료강도 |
| 구조평면도 | S-1xx, "구조평면도", "FRAMING PLAN" | 보·기둥 부호 |
| 램프상세도 | "램프", "RAMP" 상세 | 경사 표기(S=1/n, %), 폭 |
| 소방도면 | F-xxx, "소화설비", "스프링클러" | 헤드 배치, 배관 |
| 기계도면 | M-xxx, "냉동", "기계설비" | 냉동기·냉매 계통 |
| 전기도면 | E-xxx | 간선·조명 |
| 단선결선도 | "단선결선도", "SINGLE LINE" | 수전·변압기 용량 |
| 바닥상세도 | "바닥상세", "동상방지" | 바닥 단면, 히팅 배관 |
| 측량성과도 | "측량", "성과도" | 지적선 |
| 기타 | 위에 없음 | 사진, 표지, 목차 |

## 규칙

- 한 페이지에 도면이 여러 장 있으면(보고서 수록본 등) 가장 큰 도면 기준으로 분류하고, `note`에 나머지를 적는다. 층이 여러 개면 `floors`에 모두 넣는다.
- 층 라벨은 `B1`, `1F`, …, `RF`, `M1F`로 정규화한다.
- `building_id`는 `asset_meta.yaml`의 `buildings[].id` 또는 별칭으로 맞춘다. 단지 전체 도면이면 `null`.
- 글자가 뭉개져 유형조차 판단할 수 없으면 `drawing_type: 기타`, `readable: false`.
- 분류 단계에서는 **값을 읽지 않는다.** 표제란과 제목만 본다.
