## 골든 시뮬레이션에서 보이는 보정 신호 (임계값 전부 확정 가정)

- **SP02 🟡 vs 실사 양호:** 창고층 최소 유효층고(A 2F 8.09, B B1 7.91)가 🟡 기준 8.5m 미만이지만 실사는 '바닥 1단+랙 3단(6.9m 이상) 확보'로 양호 판단. 청라·석남에 이어 8.5m 기준이 높다는 사례.
- ~~SP05·SP07 ⚪~~ → 2026-10-14 해결: `terrain_multi_level_access` 필드와 handling_type '다층 지형접안형' 추가. A·B동 terrain=true, ramp_type=없음(medium) → SP07 🟢, SP05 미발동(건물 램프 없음). 진입도로 경사·폭은 G07 DD 포인트로 확인.
- ~~FR03 🟢 vs 실사 결함~~ → 2026-10-14 해결: `ohd_sprinkler_gap` 필드와 FR06 추가. A·B동 true → FR06 🟡.
- **G06·G07 🟢 vs 실사 결함:** 연식 룰이라 신축(2023)은 🟢 — 준공 하자 누수, A동 4층 주차장 부등침하 악순환이 안 잡힘(송온1·2와 같은 패턴).
- **CL04 🟡 vs 실사 양호:** 실사는 B1 상온 전환에 구조·전력 문제 없다고 판단.
