## 검토 필요

- [ ] **dock_count 192·dock_leveler_count 16**: 층당 값(Berth 24, 레벨러 2)을 창고 8개층으로 곱한 값이다. 10F 옥상 화물 28과 1F 대기 27은 뺐다.
- [ ] **ramp_slope_pct**: 곡선 내측 최대 10.69%를 정답으로, 직선 최대 8.76%도 인정했다. 임계 9%를 사이에 두고 갈리므로 어느 쪽을 기준으로 할지 정해야 한다(SP05).
- [ ] **ramp_form 나선형**: 본문에 형상 단어가 없다. 수록 평면도(p47, p55) 이미지로 판단했다.
- [ ] **structure_type**: 복합(p7 RC·철골 병기)과 SRC(p100 구조형식표) 둘 다 정답으로 둠.
- [ ] **temp**: 9F·5F(일부)는 설계 저온·운용 상온. 설계값을 정답으로 넣었다.
- [ ] **clear_height_m**: 배관하부(기준층·9F)와 보 하단(1F)으로 기준이 층마다 다르다. 1F는 일반 배관하부 실측이 없다.
- [ ] **floor_load**: 국문(p101) 25.0kN/㎡, 영문 본문은 '20.0kN/㎡(상온)'. 표 값 25.0을 정답으로 했다.
- [ ] **gross_floor_area**: 보고서는 사용승인서(111,959.24)와 준공도면(111,934.06)의 불일치를 확인 필요로 적었으나, 면적표(p8)상 차이 25.18㎡가 경비실 면적과 같다. 창고동 값 111,934.06을 정답으로 했다.
- [ ] **dock_route_column_conflict false (medium)**: 전층 Y7열 기둥 보호대 권장(p16)은 Berth 앞 기둥 충돌 노출로 보고 간섭으로 보지 않았다.
- [ ] **건축허가일**: p9 표 2020.02.15, p34 본문 2020.12.15. 골든에는 영향 없음.
