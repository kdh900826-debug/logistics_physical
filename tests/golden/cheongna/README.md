## V01 후보 (IM과 PCA 불일치)
1. 램프 경사: IM "7.5% 이하"(p13), PCA "6.41% ~ 8.52%"(p51). IM이 유리한 쪽으로 기재함.
2. 램프 폭: IM 7.4m(p13), PCA 8.0M 연석 포함(p51). 측정 기준이 다를 수 있음.
3. 구조형식 표기: IM은 "PC, 철골철근콘크리트"(p5), PCA는 본동 PC·램프 SRC(p44)이고, p25에는 "PC 구조, 철골조"로 적혀 있음.
4. 건물 높이: IM 74.1m 지하 포함(p5), PCA 최고높이 67.70m(p25). 단, PCA p20에도 "높이 74.1m"가 있음. 스키마 필드는 아님.

## 검토 필요
- **floor_load 단위**: 원문 kN/㎡을 그대로 두었음(20 kN/㎡ ≈ 2.04 t/㎡, 환산은 normalize 단계에서). 1F·3F는 상온 20을 대표값으로 적고 저온 25는 note에 남김. 사무층 5.0은 용도별 하중을 층에 대응시킨 값임.
- **clear_height_m**: PCA에 '유효고' 표현은 없고 '천정고'만 있어 이를 그대로 매핑함. 사무층 2.7m는 천장 마감고임.
- **ramp_slope_pct**: 범위(6.41~8.52) 중 최대값 8.52를 upper_bound로 기록함. 범위를 표현하는 방식은 확정이 필요함.
- **structure_type**: main을 PC로 했으나 '복합'으로 볼 여지도 있음. IM도 같은 기준으로 PC로 기록함.
- **ramp_type**: 일방향 루프형 램프임. '단방향'과 '나선형' 중 무엇으로 볼지 확인 필요함.
- **7F direct_truck_access**: 7F에는 층별 하역장 사진이나 기재가 없음. '각층 주행로'(p7)와 단면도(p37)를 근거로 true로 둠.
- **refrigerant**: 본문에는 냉매 종류가 없음. 부록 고압가스 냉동제조 자율검사증명서(p351~353)의 R-404a로 판정함.
- **refrigeration_owner (미기재)**: 냉동제조 검사증명서의 업소명이 소유자 SPV(케이피로지스틱피에프브이, 제1·3·4기계실)로 되어 있음. 임대인 소유를 시사하지만 명시적 기재가 없어 넣지 않음.
- **유니트쿨러 수량**: p26은 작업장용 74대, p186은 70대로 서로 다름. CDU 증발온도도 p10은 -30℃, p186은 -32℃.
- **기초 파일 직경**: p6·p45 본문은 Ø600, p45 표는 D500. 공작물주차장도 Ø500과 D400으로 갈림. 스키마 필드는 아님.
- **1F 공실 대수선 허가일**: p235는 2025.10.02, p296 허가서는 2025.09.05.
- **승강기 대수**: 본문은 31대(p14), 검사성적서 제목은 32대(5,000kg 2 + 1,600kg 13 + 1,350kg 17, p318). 화물용 2대는 둘 다 같음.
- **수전 24,750kW**: 이 중 5,000kW(제2전기실)는 준공 후 임차인 전용설비로 추가된 것(p12). 임차인이 퇴거하면 유지되는지 확인 필요함.
- **미기재(골든에서 제외)**: dock_count·dock_leveler_count(레벨러는 있다는 기재만 p97), vrc_count, sprinkler_type(창고 준비작동식·사무 습식이라 enum 해당 없음, 헤드 형식 미기재), fire_compartment_max_m2, cold_area_m2, cold_ratio_pct, roof_panel_core(평지붕), cold_floor_heave_protection, truck_yard_depth_m, roof_area_m2, 소유권 4종.
- **IM `building_id`**: IM은 동을 구분하지 않았지만 수치가 모두 물류창고동 값이어서 `_asset` 대신 `main`으로 넣음.
- **IM `cold_ratio_pct` 13**: 면적 기준인지 임대료 기준인지 불명확함.
- IM에는 "저온 전환 가능" 같은 마케팅 문구가 없음. 반대로 1F South가 저온에서 상온으로 전환됐다는 기재가 있음(p9).


## 정리 메모 (Claude, 2026-10-13)
- `golden_im_claims`의 구조형식을 PC → 복합으로 바꿨다. IM은 'PC, 철골철근콘크리트'를 병기했고, 추출 가이드는 병기를 `복합`으로 정했다. 실사 기준 정답(`golden_spec`)은 본동 PC 그대로 둔다 → V01 테스트 케이스(방향 없음)가 된다.
