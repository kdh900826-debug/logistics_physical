# songon 골든 샘플 (이천 송온리 물류2센터)

- 실사(정답) 출처: `230209_이천송온리물류2센터_준공실사(DD)보고서_r3.pdf` (㈜한미글로벌건축사사무소, 2023.02.07, 263p, 현장 2023.01.06·18, 발주자 ㈜코람코자산운용). IM은 없다.
- 건물 구성:
  - `main`: 가동(물류창고). B2~3F, PC+RC(지붕 철골), 2022-12-22 사용승인 신축. phase는 '원준공' 하나다.
  - `guard`: 나동(경비실) 12㎡. `role: 부속`
- 기존 `icheon`(이천 상봉리, 세방)과 다른 자산이다.
- 파일: `golden_spec.json` / `asset_meta.yaml` / `findings.yaml`(룰별 실사 소견)
- 단위는 원문 그대로 적었다(바닥하중 kN/㎡). 신뢰도 medium인 값은 본문 서술에서 끌어낸 값이다.

## 필수 학습 항목 (사용자 지정)

**지하층을 상온창고로 쓰면 40FT 컨테이너 차량 이동이 제한된다 (p40, 같은 내용 p16·p48·p82).**

- B2 하역주차장의 컨테이너 주차 위치가 준공도면과 다르게 실시설계 기준으로 시공됐다. 이 위치에서는 출차 동선의 회전반경이 너무 작아(도면 표기 R-12M), 최좌측 40FT 컨테이너 차량은 한 번에 출차 램프로 진입하기 어렵다.
- 지상1층→지하2층 램프 폭이 4m라 40FT 컨테이너가 곡선구간에서 양방향 교행하기 어렵다.
- B2가 냉동창고일 때는 40FT 운행이 없어 문제가 되지 않는다. B2를 상온창고로 운영할 때 고려해야 할 사항이다(주차위치 조정, 운영 시 주차관리).

엔진 반영:
- 판정: `ramp_width_m` 4.0(양방향) → SP05 🔴 (기준 7.5m 미만).
- 회전반경: 2026-10-13 `turning_radius_m` 필드와 SP08(대형차 회전반경 부족)을 추가했다. 골든 값 12.0m(p40 도면 R-12M). 🔴 기준 12.0m(세미트레일러 최소회전반지름)과 같아 🔴는 아니고, 🟡 여유 기준은 사용자 결정 대기다.
- SP05·SP06·SP08·CL04의 DD 확인 포인트에 이 사례를 넣었다(`rules_spec.md`, `rules_cold.md`).
- `findings.yaml`의 SP05·SP06·SP08·CL04에 `[필수]`로 기록했다.

## 결함·운영 소견 (룰 관련)

- 램프: 40FT 출차 회전반경·램프 폭 4m 교행 제약 (p40) — **필수**
- 램프: 지상1→3층 램프 이중벽·경사, 난간 후레싱 누수 사고. 일부 누수가 지속된다 (p39, p42)
- 도크: 전층 도크레벨러 미설치 (p24, p29)
- 지붕: 선홈통 동결 탈락 → 창고 누수 사고(2023.01.07, 보수 완료). 거터 열선 필요 (p41, p18)
- 3층 하역장: 트렌치 마감 미흡 → 2층 누수 (p25)
- 방화: 2층 하역장(필로티 주차)-창고 사이 방화구획 미시공 (p33)
- 층고: 3층 9m → 7.7m 축소, B2 일부 8.4m (p23, p27)
- 저온: 환기창·간벽부 결빙, 방열 보수 흔적·크랙 (p28-29)
- 설비: 상온창고 환기설비 미반영(추가 약 1.4억원), 주차관제 미설치 (p60, p85)
