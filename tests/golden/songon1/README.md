# songon1 골든 샘플 (이천 송온리 물류1센터)

- 실사(정답) 출처: `첨부 2. 211124_이천송온리물류1센터_준공실사(DD)보고서.pdf` (㈜한미글로벌건축사사무소, 2021.11.22, 159p, 현장 2021.11.10·12, 발주자 ㈜코람코자산운용). IM은 없다.
- 건물 구성:
  - `main`: 가동(물류창고). B2~3F, PC+RC(지붕 철골), 2021-10-19 사용승인 신축. phase는 '원준공' 하나다.
  - `guard`: 나동(경비실) 12㎡. `role: 부속`
- 같은 단지의 물류2센터는 `songon`(확인표 '송온2')이다. 이 자산은 확인표에서 '송온1'로 보인다.
- 파일: `golden_spec.json` / `asset_meta.yaml` / `findings.yaml`(룰별 실사 소견)
- 단위는 원문 그대로 적었다(바닥하중 kN/㎡). 신뢰도 medium인 값은 본문 서술에서 끌어낸 값이다.

## 필수 학습 항목 (사용자 지정)

1. **온도대 변경이 남긴 바닥 단차 (p19).** 지상2층 창고와 ELEV홀 사이에 단차가 있다. 골조공사가 끝난 뒤 냉동창고가 상온창고로 바뀌면서 바닥 마감 두께가 달라져 생겼다. 운영이 불편하고 보행 안전사고 우려가 있어 경사로 등 조치가 필요하다.
   - 같은 변경으로 수전용량이 4,000kW에서 3,500kW로 줄었다(p48). 다시 냉동으로 바꾸려면 수전 증설이 필요하다.
2. **램프→하역장 동선상 기둥 (p21).** 지상2층 램프에서 하역장으로 가는 동선에 기둥이 있어 40ft 트레일러 같은 대형차가 진출입하기 어렵다. 보고서는 기둥보호대, 안내원 배치, 대형차의 3층 유도 같은 운영 조치를 제시했다(결론 p61: 반대차선 침범, 한 번에 진출입 어려움).

엔진 반영:
- 기둥 간섭: 2026-10-13 층 단위 필드 `dock_route_column_conflict`와 SP09(하역 동선 기둥 간섭)를 추가했다. 2F = true(p21) → SP09 🟡.
- 바닥 단차는 판정 필드가 없어 룰 DD 확인 포인트에 사례로 넣었다.
  - CL04(온도대 전환 유연성): 전환 흔적(바닥 단차, 수전 감소), 냉동 하역장 기둥 간격 — `rules_cold.md`
  - SP05(램프·차량 접근 제약): 램프→하역장 진입 동선상 기둥 간섭 — `rules_spec.md`
- `findings.yaml`의 CL04·SP05·SP09에 `[필수]`로 기록했다.

## 검토 필요

- [ ] **B2·1F temp = 냉동**: 설계는 냉동창고, 실사 시엔 냉장(-4~5℃)으로 운용 중(p44).
- [ ] **ramp_type·ramp_form**: 본문 서술에서 끌어낸 값이라 도면 확인이 필요하다.
- [ ] **주소 지번**: p7 '422번지'와 p2·p6·p14 '442번지'가 다르다. 442로 넣었다.
- [ ] **구조편 층 용도**(p39 '지하1~2층 냉동, 지상1~3층 상온')는 건축편과 달라 무시했다.

## 결함·운영 소견 (룰 관련)

- 온도대 전환: 2층 단차·수전 감소 (p19, p48), 1층 냉동 하역장 대형차 기둥 통과 곤란 (p14) — **필수**
- 램프: 2층 램프→하역장 기둥 간섭 (p21, p61), 곡선구간 40ft 반대차선 침범 (p36) — **필수**
- 층고: 전 창고층 8~9.2m라 3단 랙(4단 파렛)이 어렵다 (p17, p21)
- 저온: B2 냉동창고 대부분 누수·결로 결빙, 방열 미시공 기둥 결로, 환기창 누기 결빙 (p23-24)
- 화재: 지붕·외벽 EPS 판넬, 냉동창고 우레탄 난연코팅 성적서의 바탕모재가 현장과 다름 (p15-16, p21)
- 전기: 전기실·발전기실 상부가 방수 없는 냉동창고라 결로 누수 우려 (p48-49)
- 법규: 지하2층 조경 일부 삭제 — 조례 15% 미달 판단 (p35)
- 누수: 건축물-램프 신축 조인트, 램프 단부 누수 (p14, p61)
